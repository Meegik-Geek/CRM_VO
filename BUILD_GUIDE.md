# 📘 Гайд зі створення інсталятора CRM "Вступ.Офіс"

Цей документ допоможе вам зібрати проект в один EXE-файл для розповсюдження.

## 1. Підготовка середовища
Переконайтеся, що всі бібліотеки встановлені:
```bash
pip install -r requirements.txt
```

## 2. Збірка Python проекту (cx_Freeze)
Цей крок перетворює ваші скрипти (`main.py`, `installer_wizard.py`) на виконувані файли.
1. Відкрийте термінал у папці проекту.
2. Запустіть команду:
   ```bash
   python setup.py build
   ```
3. Після завершення у папці `build/` з'явиться папка з назвою типу `exe.win-amd64-3.14`. **Це ваша робоча програма.**

## 3. Створення фінального інсталятора (Inno Setup)
Щоб отримати один файл `Setup.exe`:
1. Встановіть [Inno Setup](https://jrsoftware.org/isdl.php).
2. Відкрийте файл `installer/setup_script.iss`.
3. **ВАЖЛИВО**: У рядку 35 перевірте назву папки з кроку 2.
4. Покладіть інсталятор PostgreSQL (назва `postgresql-installer.exe`) безпосередньо у **корінь проекту** (поруч із `setup.py`).
5. Натисніть **Compile** в Inno Setup.

## 4. Оновлення при змінах у коді
1. Видаліть папку `build/`.
2. Запустіть `python setup.py build`.
3. Перекомпілюйте проект в Inno Setup.

---

### 💡 Поради:
* **PostgreSQL**: Файл `postgresql-installer.exe` тепер є опціональним компонентом. Якщо ви його поклали в корінь, користувач зможе вибрати його встановлення під час інсталяції.
* **Автоматизація**: Майстер налаштування бази даних запуститься автоматично після завершення копіювання файлів.
* **Іконки**: Змінюйте `resource/logo.ico`, щоб змінити вигляд ярликів.
* **Ліцензія**: Текст ліцензії можна змінити у файлі `installer/license_uk.txt`.
